### Key Takeaways

##  How to Create a Shortcut That Opens All Your Work Apps

 To get started, open the [Shortcuts](https://apps.apple.com/us/app/shortcuts/id915249334) app on your Mac. Then click the New Shortcut button at the top of the window, shown by the “+” icon. Search for the “Open App” action and drag it into the main window. Then click the “App” button and choose what you want to open first.

 If you need to open a specific file in an app, add the “Open File” action instead. Then click “File” and choose what to open; you can also specify a particular app if you don’t want to use the default.

 If you don’t see a “File” button, click “App” instead and then hit the “Clear” option.

 Repeat these steps to add a new action for every app or file you use throughout a typical workday. Make sure whatever app or file you want to use first is at the bottom of the list, so it opens after everything else. Just drag and drop the actions if you need to rearrange them.
