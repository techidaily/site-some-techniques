##  How to Remove Cryptocurrency From Brave on Desktop

 First, open your [Brave browser](https://instagram-videos.techidaily.com/updated-2024-approved-enhancing-visual-storytelling-on-instagram-with-loops/) so we can get it cleaned up and ready to go. The options for crypto-related content are scattered throughout the browser's settings, so we'll be doing some clicking around.

 If you have multiple profiles set up on Brave, be aware that changes to these settings will apply only to the current profile. You'll need to repeat them for each profile.

###  Opt-Out of Brave Rewards and Disable Tip Buttons

 Somewhat like [Microsoft Edge's Rewards](https://easy-unlock-android.techidaily.com/how-to-change-oppo-find-x6-pro-lock-screen-clock-in-seconds-by-drfone-android/) feature, Brave has an optional rewards program allowing you to earn funds by viewing ads. If you previously opted-in but are no longer interested, you can disable Brave Rewards entirely on your browser.

 Start by entering this shortcut into the address bar:

brave://settings

 Alternatively, click the hamburger menu (three horizontal lines) in the top-right corner of Brave. Then click "Settings" in the drop-down menu that appears.

![Click the hamburger menu followed by "Settings"](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/01/brave-settings-menu.png) 

 In the left-hand menu of the Settings page, click "Brave Rewards."

![Click the hamburger menu followed by "Settings"](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/01/brave-settings-menu.png) 

 You'll see a list of various Rewards-related settings with toggle buttons. Toggle them all off. However, if you have remaining BAT, you may want to leave the "Auto-Contribute" settings turned on to make sure it gets distributed.

![Toggle off all of the Brave Rewards settings.](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/01/brave-rewards-settings.png) 

 With them all turned off, you'll cease to see any ads, earn any BAT, or see any tip buttons on the websites you visit.

###  Hide the Brave Rewards Button From the Address Bar

 If you're not using the Brave Rewards feature, you can hide the icon from the address bar so that it doesn't get in your way.

 Remaining on the Settings page, click "Appearance" in the left-hand menu.

![Click the hamburger menu followed by "Settings"](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/01/brave-settings-menu.png)

###  Banish the Crypto Wallet From the Toolbar

 If you don't want the [crypto wallet](https://fox-that.techidaily.com/iphone-users-troubleshoot-your-contacts-app-issues-with-these-simple-solutions/) visible next to the address bar, removing it is easy.

 On the Settings page, click the "Wallet" button on the left-hand menu.

![Click the hamburger menu followed by "Settings"](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/01/brave-settings-menu.png) 

 In the options that appear, toggle off "Show Brave Wallet Icon in the Toolbar."

![Find the option for showing the Brave Wallet in the toolbar.](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/01/brave-wallet-settings.png)

 Some of the most aggressive promotions of cryptocurrency on Brave happen on the New Tab page, with big banner ads. To get rid of them, open a new tab and click "Customize" in the bottom-right corner of Brave's new tab page.

![Click the Customize button on the New Tab page.](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/01/brave-new-tab-customize-button.png)
