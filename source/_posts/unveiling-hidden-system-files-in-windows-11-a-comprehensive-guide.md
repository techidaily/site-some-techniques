### Key Takeaways

* Show hidden files and folders on Windows 11 easily by clicking the View button in File Explorer and selecting Show > Hidden items.
* You can also display hidden items by opening File Explorer and navigating to Options > View > "Show Hidden Files, Folders, and Drives."
* To display protected operating system files, open File Explorer, click Options, go to the View tab, and uncheck "Hide protected operating system files (Recommended)."

 Windows 11 handles [hidden files and folders](https://tech-hub.techidaily.com/learn-ai-prompt-engineering-with-our-top-5-expert-led-online-courses/) almost identically to versions of Windows that came before it: with [special file flags](https://screen-mirroring-recording.techidaily.com/new-one-click-iphone-screen-capture-for-2024/). Showing these hidden files in File Explorer is easy. Here's how.

 There are actually multiple ways to show hidden files and folders on Windows 11, but we'll walk you through the best methods to make it easier.

 First, launch [File Explorer](https://hardware-tips.techidaily.com/toms-tech-review-in-depth-analysis-and-reviews/) by opening Start and searching for "File Explorer," or by clicking the File Explorer icon in your taskbar if it's pinned there.

##  How to Show Hidden Files on Windows 11 the Easy Way

 To show hidden files on recent versions of Windows 11, you can simply click the View button on the File Explorer toolbar and then select Show -> Hidden items from the menu.

##  Show Hidden Files on Windows 11 Using Options

 When File Explorer opens, click the ellipses (three dots) button in the toolbar near the top of the window. In the menu that appears, select "Options."

![Click the three-dot menu icon in File Explorer.](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2023/11/click-the-three-dot-menu-icon-then-click-options.png)

![A hidden folder on Windows 11.](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2023/11/hidden-folder.png) 

 If you want to hide them again later, use "Options" in File Explorer to open Folder Options again, click "View," select "Don't show hidden files, folders, or drives," and click "OK."

##  How to Show Protected Operating System Files in Windows 11

 In Windows, there's another type of hidden file: a [system file](https://facebook-record-videos.techidaily.com/techniques-for-successfully-incorporating-a-streaming-youtube-playlist-for-2024/), which is hidden and protected by default to keep your operating system working properly. If you'd like to see this type of hidden file, open File Explorer, click the "three dots" button in the toolbar, then select "Options."

 In the Folder Options window, click the "View" tab, then scroll down in the "Advanced Settings" list and uncheck "Hide protected operating system files (Recommended)."

![Unhide protected system files on Windows 11.](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2023/11/hide-protected-files.png) 

 As soon as you click the check box, a new dialog window will open that warns you about the dangers of revealing protected operating system files.

 You are about to reveal sensitive operating system files. If you move or delete hidden system files, it could break your Windows 11 installation or potentially cause data loss. So proceed with extreme caution.

 If you know what you're doing and are willing to accept the risks, click "Yes."

![Click "Yes" to confirm that you want to reveal protected files.](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2023/11/click-yes.png) 

 Then close the Folder Options window by pressing "OK." As with the hidden files revealed in the section above, protected operating system files will appear translucent on your desktop and in File Explorer.

 When you're done with your task, it's usually a good idea to hide your protected operating system files again. To do that, open Folder Options as shown above, click the "View" tab, then place a checkmark beside "Hide protected operating system files (Recommended)" and click "OK." Good luck!
